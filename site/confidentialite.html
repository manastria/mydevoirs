Déclaration de confidentialité

En deux mots : MyDevoirs ne collecte aucune donnée sur vous ni sur votre enfant, ni dans le logiciel, ni sur ce site.

Dernière mise à jour : 17 octobre 2026.

Le logiciel

MyDevoirs fonctionne entièrement sur l’ordinateur où il est installé.

  • Aucun compte : il n’y a rien à créer, ni nom, ni adresse électronique à donner.
  • Aucun envoi de données : le logiciel ne se connecte à aucun serveur. Il ne contient ni statistiques d’usage, ni rapport d’erreurs automatique, ni publicité.
  • Vos devoirs restent chez vous : devoirs, matières et couleurs sont enregistrés dans un seul fichier de base de données sur l’ordinateur. L’emplacement de ce fichier est affiché dans les paramètres.

Le seul lien vers l’extérieur est un lien d’aide, dans les paramètres : il ouvre la page du projet dans votre navigateur, uniquement si vous cliquez dessus.

Si vous placez vous-même le fichier de base de données dans un dossier synchronisé (Dropbox, Seafile, Box…), c’est ce service qui stocke une copie de vos devoirs, selon ses propres règles. MyDevoirs n’y participe pas et n’y a pas accès.

Ce site

  • Aucun cookie, aucun outil de mesure d’audience, aucun traceur.
  • Aucune ressource extérieure : polices, images et scripts viennent tous du site lui-même.
  • Aucun formulaire : le site ne vous demande aucune information.

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub reçoit votre adresse IP et des informations techniques de votre navigateur lorsque vous consultez une page, et peut les conserver dans ses journaux. Ces données sont traitées par GitHub, pas par MyDevoirs : voir la déclaration de confidentialité de GitHub.

Télécharger et demander de l’aide

Les fichiers d’installation sont téléchargés depuis GitHub, qui traite alors votre connexion comme décrit ci-dessus.

Les retours (bugs, idées, questions) passent par les « issues » du dépôt GitHub. Elles demandent un compte GitHub et sont publiques : tout ce que vous y écrivez peut être lu par n’importe qui et indexé par les moteurs de recherche. N’y mettez aucune information personnelle : ni nom, ni prénom, ni école, ni adresse électronique, et rien qui permette d’identifier un enfant.

Les enfants

MyDevoirs est pensé pour des enfants, et c’est justement pour cela qu’il ne recueille rien : il n’y a aucune donnée d’enfant à protéger côté projet, puisqu’aucune ne nous parvient.

Questions et modifications

Pour une question sur cette déclaration, ouvrez une question sur GitHub, en gardant à l’esprit qu’elle sera publique.

Si le logiciel ou le site change d’une façon qui touche aux données (par exemple une mise à jour automatique), cette page sera mise à jour en conséquence. L’historique de ses modifications est visible dans le dépôt.
